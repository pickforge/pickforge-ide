# PickForge v0.2.1

PickForge IDE was retired on September 3, 2026. This is its final release.

- The updater now checks the archived `pickforge/pickforge-ide` repository, so it can never consume update metadata published by the successor product at the old repository path.
- The app shows a one-time retirement notice with links to the new [Pickforge](https://pickforge.dev) and the [archived IDE repository](https://github.com/pickforge/pickforge-ide).

Existing installs keep working offline. There will be no further updates.
